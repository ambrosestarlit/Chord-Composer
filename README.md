# Chord Composer

GitHub Pagesでそのまま公開できる、ブラウザ完結型のコード進行・伴奏作成ツールです。

## 主な機能

- 左3：右7の2ペイン構成
  - 左：読み込み・書き出し、再生・挿入設定、コード進行テンプレート
  - 右：コード一覧、挿入済みコード進行
- デスクトップ表示では左ペインと右ペインを個別に縦スクロール
- コードボタンをクリックして試聴
- 選択中のコードを進行へ追加
- 挿入済みコードを横一列で表示し、横スクロールで操作
- カードの余白をダブルクリックして削除
- 挿入後の各コードの拍数を1〜32拍で変更
- BPM一括設定、メトロノームON/OFF
- 倍音を重ねたピアノ音色で再生し、低いルート音も聞き取りやすく補強
- コードごとに以下の演奏方法を設定・変更
  - ベタ打ち
  - 四分弾き
  - アルペジオ
  - 単音バッキング
  - カウンターメロディ
  - フィルイン
  - オスティナート
- 単音バッキング、カウンターメロディ、フィルイン、オスティナートは、コードが長くても各コード内で1巡のみ演奏
- フィルインはコード区間の終わりに合わせて1巡
- 左手ルート音、コード末尾の裏拍ルート音をコードごとに設定
- 左手ルート音を維持したまま、右手コードを自動転回して滑らかに接続
- 既存コード進行テンプレートの試聴・一括挿入
- 現在の進行を任意名のユーザーテンプレートとして保存
- MIDI / WAV書き出し
- JSONプロジェクトの読み込み・書き出し

## JSONプロジェクトに保存される内容

- コード進行
- 各コードの拍数、演奏方法、ルート音、裏拍
- BPM、メトロノーム、挿入設定
- 選択中のコード種類
- 保存したユーザーテンプレート

JSONを読み込むと、現在のプロジェクト内容を読み込んだ内容へ置き換えます。

## GitHub Pagesへの設置

1. `index.html`、`style.css`、`app.js` をGitHubリポジトリのルートへ配置します。
2. リポジトリの `Settings` → `Pages` を開きます。
3. `Deploy from a branch` を選択します。
4. 公開するブランチと `/ (root)` を選択して保存します。

ビルド処理や外部ライブラリは不要です。

## ブラウザ内の自動保存

作業中の状態はブラウザの `localStorage` にも保存されます。別端末への移動やバックアップにはJSON書き出しを使用してください。


## 使い方ポップアップ

画面上部の「使い方」ボタンから、コード挿入、個別設定、テンプレート、再生、削除、JSON保存・読み込み、MIDI/WAV書き出し、各演奏方法の違いを確認できます。

ポップアップは右上の×、下部の「閉じる」、背景クリック、Escキーで閉じられます。

- 挿入後のコードは、各カードの拍数欄から1〜32拍へ変更できます。
